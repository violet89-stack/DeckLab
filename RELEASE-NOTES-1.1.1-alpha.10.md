# DeckLab 1.1.1-alpha.10 — GALLEON module-focused preview

This patch simplifies the Corsair GALLEON 100 SD representation. Device Studio now uses Elgato's official close-up artwork of the dedicated Stream Deck module rather than shrinking the entire keyboard into the preview.

The 12 LCD keys, two rotary encoders, and two non-touch Encoder feedback regions are aligned directly to that reference image. Because DeckLab 1.1.x uses one canonical DeviceSurface, the same module-focused rendering is used in Preview, Build, and compatibility views.

The official reference artwork remains attributed under CC BY 4.0 in `THIRD-PARTY-NOTICES.md` and `assets/elgato/ATTRIBUTION.md`.
