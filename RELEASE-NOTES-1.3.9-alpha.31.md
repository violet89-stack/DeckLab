# DeckLab 1.3.9-alpha.31 — licensing, colour templates and icons

- Adopts MPL-2.0 for DeckLab source, with the official complete licence and SPDX source identifiers.
- Records CC BY 4.0 attribution to Elgato and Will Johnson for product previews and colour templates, with source/licence links and supplied evidence.
- Adds Colour templates in Build beside the selected action, inside My artwork, and in the LCD artwork editor. Flat, Stroke, Gradient and Glass finishes offer 93 colour/tone combinations from 38 original sheets.
- Crops the requested key or LCD panel from the source sheet, preserving source pixels. Full-surface matching tiles four/six panels for +/+ XL and 2×2 for GALLEON. Whole-panel and alternative compositions are also available.
- Preserves action assignments and titles; supports Undo, saving to My artwork, independent regions and project persistence. Attribution metadata accompanies template recipes and library artwork.
- Corrects displayed colour names for three mislabeled Stroke source files without changing the supplied PNGs.
- Adds 1,241 MIT-licensed Elgato icons inside the artwork library, with search, regular/filled variants, monochrome colour selection, transparent rendering, click/drag placement and save-to-library support. Exported profiles retain the complete MIT notice.
- Creates the public violet89-stack/DeckLab repository and enables private vulnerability reporting.

Previous local-companion security fixes and LCD/dial repairs remain included. Windows desktop/GPU behaviour, the first GitHub CI run and physical hardware comparisons remain unverified in this environment. Current test evidence is under verification/1.3.9/.
