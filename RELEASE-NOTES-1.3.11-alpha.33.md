# DeckLab 1.3.11-alpha.33 — built-in Neo Dino Runner

- Added Built-in samples to the artwork picker, alongside My artwork and Elgato icons.
- Bundled the Neo Dino Runner: a full-width 232 × 50 GIF with a running dinosaur, scrolling scenery and an eight-second loop.
- Animated thumbnail, click-to-apply and dock-and-drag onto an empty Infobar work offline. Dragging creates an Artwork only action.
- Sample placement preserves the selected action and background. Original GIF bytes survive profile save/reopen; the optional My artwork copy supports favourites.
- Included editable poses, a regeneration script and provenance notes for the sample.
- Added a browser regression suite and bundled-asset integrity checks. Physical Neo playback remains unvalidated.
