DECKLAB 1.3.12 COMMUNITY ALPHA — WINDOWS QUICK START

1. Close any earlier DeckLab PowerShell/companion window. Extract this release into a new folder.
2. Open the extracted folder in File Explorer.
3. Click the File Explorer address bar.
4. Type:

   powershell

5. Press Enter.
6. Run:

   py -3 decklab_host.py

   If Windows says `py` is not recognised, try:

   python decklab_host.py

7. Open this address if DeckLab does not open automatically:

   http://127.0.0.1:8975

FIRST TEST
- Click Load demo plugin.
- Click Build demo profile.
- Open Device Studio → Build for Actions & artwork, Layouts & assets, and Icon library.
- Try Original, Backlit effect and Light off in Display appearance.
- Select a physical dial to change its action. On GALLEON, click a top/bottom LCD region to choose the dial action.
- Advanced contains Test and Inspect; Reports contains protocol coverage.
- Help should show 1.3.12 Community Alpha. Use the same localhost address/port to retain browser data.

FOUND A BUG?
- Take a screenshot for visual issues.
- Click Create bug report in the Project toolbar.
- Review the ZIP before posting it publicly.
- Attach it to the GitHub bug-report template.

SECURITY
DeckLab does not automatically start plugin programs and does not include a .bat/.cmd/exe launcher. Static inspection does not execute imported plugin application code.

OPTIONAL LIVE DEMO
If Node.js is installed, open a SECOND PowerShell window in the DeckLab folder and run:

node "examples\live-plugin\com.decklab.live.sdPlugin\bin\plugin.js" -port 8975 -pluginUUID com.decklab.hostdemo -registerEvent registerPlugin -info "{}"

Only run plugin code you trust. Close that process when finished.
