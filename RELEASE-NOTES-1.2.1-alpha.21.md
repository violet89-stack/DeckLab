# DeckLab 1.2.1-alpha.21

- Six built-in LCD demos: Volume, Brightness, CPU monitor, Memory monitor, Now playing and Counter. Available on Keypad, Encoder and Neo surfaces without loading a plugin. Find LCD demos near the top of Actions.
- Rotate with the wheel or arrow keys; press with the pointer, Enter or Space. Tap touch surfaces or click keys in Live Preview. Monitor readings and media tracks are sample data; these demos do not control the computer.
- My artwork opens from Choose image in the selected action inspector. Upload multiple PNG/JPEG/GIF/WebP files, search by filename, apply, remove, export and import a collection. Animated GIF data is preserved.
- Images are stored in IndexedDB in this browser. Export before clearing browser data or changing origin/port. Profile exports embed placed images independently of the collection.
- Fixed refreshes on LCD actions without a feedback layout, title-size CSS overriding the inspector, and duplicate root-page breadcrumbs.
- Added dial keyboard controls, visible keyboard focus and height-aware LCD typography.

See TESTING.md for checks and limitations. SDK coverage is unchanged from alpha.20; this release focuses on the studio workflow.
