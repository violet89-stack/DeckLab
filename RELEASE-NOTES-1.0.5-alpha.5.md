# DeckLab 1.0.5-alpha.5 — Studio rackmount calibration

This Community Alpha corrects Stream Deck Studio from a generic desktop 4×8 preview to a long professional rackmount control surface.

### Changed
- 2×16 LCD-key face instead of 4×8.
- Left/right push encoders integrated at the ends of the rack face.
- 19-inch / 1U visual treatment with rack ears.
- Published 447 × 80 × 44 mm chassis metadata.
- Matching Profile Lab and compatibility previews.
- Automatic migration for legacy DeckLab 4×8 Studio profiles.

No plugin-launch permissions or security boundaries changed in this build.
