# DeckLab 1.1.4 alpha.16 — Elgato focus

Discover now focuses on Elgato Stream Deck.

- Official Elgato Marketplace browse link opens the plugin category in your browser. Marketplace listings are not mirrored inside DeckLab.
- OpenDeck remains as a community discovery source for Stream Deck candidates, labelled untested in DeckLab.
- Removed Stream Dock discovery, refresh adapter and cached results from earlier builds. Explicitly labelled Stream Dock JSON imports are rejected.
- Local package inspection and saved local package metadata remain available. Local inspection is not a guarantee of runtime compatibility.

Validation: JavaScript syntax, Python compile, catalogue interaction harness and source rejection checks. Full browser visual verification remains outstanding.
