# Elgato Icons

Source: https://github.com/elgatosf/icons
Pinned package: `@elgato/icons` 2.5.1, from the official npm package.
Licence: MIT. Copyright (c) 2025 Corsair Memory Inc.
The complete upstream licence is included in [LICENSE](LICENSE) and the catalogue metadata.

The catalogue contains 1,241 distinct icon names/variants, choosing the largest available SVG size (24, 20 or 16 px). Original SVG strings and their SHA-256 hashes are retained. DeckLab renders these at 144 × 144 with padding, optional monochrome recolouring and transparent backgrounds. Explicit colours in multicolour icons are retained. Applied artwork and exported profiles carry the full MIT notice.

Rebuild with `python scripts/import-elgato-icons.py /path/to/elgato-icons-2.5.1.tgz`. The importer verifies the pinned npm integrity and accepts only static SVG content. No upstream executable code, React components or fonts are bundled.
