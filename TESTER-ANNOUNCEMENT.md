# Draft tester invitation — do not post until publication is complete

DeckLab **1.3.9-alpha.31** is an independent local studio for Stream Deck profiles, artwork and plugin testing. I’m looking for a small group to test key/LCD alignment, dial interactions, profile save/reopen and plugin compatibility.

You can explore built-in demos, create artwork, import readable icon packs/profiles and compare virtual device models. DeckLab does not automatically launch imported plugin programs. Live testing requires you to start trusted plugin code yourself.

This is a community alpha, with partial protocol coverage and no claim of physical hardware certification. It is not affiliated with or endorsed by Elgato or CORSAIR.

Useful reports include the build, OS/browser, device/colour, zoom/scaling, steps and expected/actual behaviour. Attach screenshots and a reviewed Create bug report ZIP. Please distinguish a simulated result from a comparison with hardware you own.

Priority devices: Stream Deck +, + XL, Neo, MK.2, XL, GALLEON 100 SD and Studio.

Download and issues: add the actual pre-release URL after the repository is created and release checks pass. Follow COMMUNITY-ALPHA.md for the short test guide.
